Release path

What a vendor submits for release.

01 Evidence

Delivery package

Requirements traceability, completed user stories, design artifacts, configuration records, deployment notes, and exception log.

02 Acceptance

UAT and stakeholder validation

Test scripts, UAT results, acceptance notes, open defects, severity ratings, workarounds, and business-owner disposition.

03 Technical

Code and architecture review

Code-review findings, integration health, security posture, data handling, performance risks, and deployment readiness.

04 Score

Go-live confidence threshold

Libertas scores the release request against the agreed threshold. If the threshold is met, the vendor has a documented basis for release.
